ระบบสารสนเทศความสัมพันธ์ระหว่างสิ่งมีชีวิตในระบบนิเวศ

ประเภทความสัมพันธ์ ภาพรวม ตารางสรุป (+/-/0) ทดสอบความรู้
ชีววิทยา

รูปแบบความสัมพันธ์ระหว่างสิ่งมีชีวิต

เลือกตัวกรองด้านล่างเพื่อศึกษาความสัมพันธ์แต่ละประเภท พร้อมตัวอย่างจริงในธรรมชาติ

ภาวะพึ่งพากัน ( + / + )

Mutualism

เป็นความสัมพันธ์ที่สิ่งมีชีวิตทั้งสองชนิดได้ประโยชน์ร่วมกัน และไม่สามารถแยกจากกันได้เลยตลอดชีวิต หากแยกกันจะตาย

ตัวอย่างคลาสสิก:

  • ไลเคน (Lichen): สาหร่ายกับรา
  • โปรโตซัวในลำไส้ปลวก: ย่อยเซลลูโลส
  • แบคทีเรียไรโซเบียมในปมรากถั่ว
ภาวะได้ประโยชน์ร่วมกัน ( + / + )

Protocooperation

สิ่งมีชีวิตทั้งสองฝ่ายได้ประโยชน์ร่วมกันเช่นกัน แต่สามารถแยกกันอยู่ได้โดยไม่อันตรายถึงชีวิต เป็นการอยู่ร่วมกันเพื่อความสะดวกสบายชั่วคราว

ตัวอย่างคลาสสิก:

  • นกเอี้ยงกับควาย: นกกินแมลง ควายได้ทำความสะอาด
  • ดอกไม้กับแมลงทั่วไป: ผสมเกสร
  • ปูเสฉวนกับดอกไม้ทะเล (Sea Anemone)
ภาวะอิงอาศัย ( + / 0 )

Commensalism

เป็นความสัมพันธ์ที่ฝ่ายหนึ่งได้ประโยชน์ (+) ส่วนอีกฝ่ายไม่ได้และไม่เสียประโยชน์ (0) เช่น ได้ที่อยู่อาศัยหรือเศษอาหาร

ตัวอย่างคลาสสิก:

  • ฉลามกับเหาฉลาม (Remora)
  • กล้วยไม้บนต้นไม้ใหญ่ (Epiphyte)
  • นกทำรังบนต้นไม้ใหญ่
ภาวะปรสิต ( + / - )

Parasitism

ฝ่ายหนึ่งเป็นผู้ "อาศัย" (Parasite) ได้ประโยชน์ (+) ส่วนอีกฝ่ายเป็น "ผู้ถูกอาศัย" (Host) เสียประโยชน์ (-) มักดูดสารอาหารแต่ไม่ทำให้เจ้าบ้านตายทันที

ตัวอย่างคลาสสิก:

  • เห็บ หมัด เหา บนตัวสัตว์หรือคน
  • พยาธิในร่างกายมนุษย์/สัตว์
  • กาฝากบนต้นไม้ใหญ่
ภาวะล่าเหยื่อ ( + / - )

Predation

ผู้ล่า (Predator) ได้ประโยชน์ (+) ในการจับเหยื่อเป็นอาหาร ส่วนเหยื่อ (Prey) เสียประโยชน์ (-) ถูกทำลายชีวิตเพื่อเป็นพลังงานในห่วงโซ่อาหาร

ตัวอย่างคลาสสิก:

  • สิงโตล่าม้าลายในทุ่งหญ้า
  • กบกินแมลง
  • เหยี่ยวล่าปลาในแม่น้ำ
ภาวะการแข่งขัน ( - / - )

Competition

เกิดขึ้นเมื่อสิ่งมีชีวิตมีความต้องการปัจจัยในการดำรงชีวิต (เช่น อาหาร แสง น้ำ คู่) เหมือนกันและมีจำกัด ทั้งสองฝ่ายจึงเสียประโยชน์ (-) เพราะต้องแย่งชิงพลังงานและเสี่ยงพ่ายแพ้

ตัวอย่างคลาสสิก:

  • ต้นไม้ใหญ่แย่งแสงแดดในป่าทึบ
  • สิงโตกับไฮยีน่าแย่งเหยื่อกัน
  • วัชพืชแย่งปุ๋ยกับต้นข้าวในนา
ภาวะหลั่งสารยับยั้ง ( - / 0 )

Amensalism

ฝ่ายหนึ่งเสียประโยชน์ (-) จากการถูกสารเคมีหรือกระบวนการบางอย่างยับยั้งการเจริญเติบโต ขณะที่อีกฝ่ายไม่ได้และไม่เสียประโยชน์ (0)

ตัวอย่างคลาสสิก:

  • ราเพนนิซีเลียมหลั่งสารฆ่าแบคทีเรีย
  • ต้นสนบางชนิดหลั่งสารขัดขวางหญ้ารอบข้าง
ภาวะกินซาก / อิงอาศัยอื่นๆ ( + / 0 )

Scavenging & Neutralism

ภาวะกินซาก (Scavenger): สัตว์กินซากสัตว์ที่ตายแล้วเป็นอาหาร ได้ประโยชน์ (+) โดยซากสัตว์นั้นตายไปแล้วจึงไม่มีผลกระทบ (0) และ ภาวะเป็นกลาง (Neutralism): สิ่งมีชีวิตอยู่ร่วมพื้นที่แต่ไม่เกี่ยวข้องกันเลย

ตัวอย่างคลาสสิก:

  • แร้งกินซากสัตว์ที่เสือล่าไว้
  • กระรอกกับกวางในป่าเดียวกัน
Ecosystem Symbiosis & Interactions

สิ่งมีชีวิตพึ่งพาและเกี่ยวพันกันอย่างไรในธรรมชาติ?

ในธรรมชาติ ไม่มีสิ่งมีชีวิตใดสามารถดำรงชีวิตอยู่ได้อย่างโดดเดี่ยว ทุกชนิดต่างต้องพึ่งพา แย่งชิง หรือเกื้อกูลกันเพื่อความอยู่รอดและการถ่ายทอดพลังงาน Dashboard นี้รวบรวมและจำแนกรูปแบบความสัมพันธ์ทางนิเวศวิทยาไว้อย่างครบถ้วนเข้าใจง่าย

สำรวจความสัมพันธ์ เล่นเกมทายภาวะ

สรุปสัญลักษณ์สลักสำคัญ

สัญลักษณ์สากล
+ ได้ประโยชน์ เติบโต/มีชีวิตดีขึ้น
- เสียประโยชน์ ถูกทำลาย/สูญเสียพลังงาน
0 ไม่ได้/ไม่เสีย ไม่มีผลกระทบใดๆ
สรุปเชิงเปรียบเทียบ

ตารางสรุปผลกระทบความสัมพันธ์ (+, -, 0)

ตารางสรุปความสัมพันธ์ของสิ่งมีชีวิตชนิดที่ 1 (Species A) และ ชนิดที่ 2 (Species B)

รูปแบบความสัมพันธ์ ชนิดที่ 1 (Species A) ชนิดที่ 2 (Species B) ตัวอย่างสำคัญ
ภาวะพึ่งพากัน (Mutualism) + + ไลเคน (สาหร่าย + รา), โพรโทซัวในลำไส้ปลวก
ภาวะได้ประโยชน์ร่วมกัน (Protocooperation) + + นกเอี้ยงกับควาย, ปูเสฉวนกับดอกไม้ทะเล
ภาวะอิงอาศัย (Commensalism) + 0 ฉลามกับเหาฉลาม, กล้วยไม้บนต้นไม้ใหญ่
ภาวะปรสิต (Parasitism) + - เห็บหมัดบนตัวสุนัข, กาฝากบนต้นไม้
ภาวะล่าเหยื่อ (Predation) + - สิงโตล่าม้าลาย, กบกินแมลง
ภาวะการแข่งขัน (Competition) - - ต้นไม้แย่งแสงแดด, สิงโตกับไฮยีน่าแย่งเหยื่อ
ภาวะหลั่งสารยับยั้ง (Amensalism) - 0 ราเพนนิซีเลียมยับยั้งแบคทีเรีย
